<h2>Game Overview</h2>
Mjölnir vs Aliens is a fast-paced arcade game built for the web. Players take on the role of Thor, wielding his legendary hammer to repel waves of alien invaders popping out of cosmic portals. The game features a responsive design, multiple difficulty tiers, and a local "Hall of Heroes" to track your legendary progress.

<h2>Key Features</h2>

<ul>
<li><strong>Mjölnir Hammer Mechanic:</strong> Custom-coded mallet cursor with dynamic "whacking" animations and sound effects.</li>
<li><strong>Adaptive Difficulty:</strong> Choose between <em>Easy</em>, <em>Medium</em>, and <em>Hard</em> modes—each with unique spawn rates and timers.</li>
<li><strong>Hall of Heroes:</strong> Integrated history dashboard that tracks your total whacks and lifetime best streaks.</li>
<li><strong>Cinematic Experience:</strong> AI-generated splash screen and lightning effects to set the mood of the battlefield.</li>
<li><strong>Fluid Responsiveness:</strong> Optimized for all screen sizes, ensuring the battlefield fits perfectly on desktop and mobile.</li>
</ul>

<h2>Technical Stack</h2>

Frontend: HTML5, Tailwind CSS for modern glassmorphism UI.

Logic: Vanilla JavaScript (ES6+) for game loop and state management.

Audio: Web Audio API for synthetic "bonk" and game-over sound effects.

Storage: LocalStorage API for persistent score tracking without a backend.

Visuals: SVG-based game assets and CSS3 animations.

<h2>How to Play</h2>

Open the game in any modern web browser.

View your past performance in the Hall of Heroes.

Select your difficulty level.

Click "Defend Asgard" and start whacking as many aliens as possible before the timer runs out!
